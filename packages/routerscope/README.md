# routerscope

> Status: pre-alpha. See the [project README](https://github.com/dalcorsogabriel/routerscope) for the vision and roadmap.

The application: capture (collector, local SSH recording proxy, importers), storage (SQLite + FTS5), services (search, diff, locate, where-used, suggestions, simulation) and interfaces (CLI, local API, web UI, MCP server).
