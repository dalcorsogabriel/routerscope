# Implementation plan: v0.1 "Everything offline"

Goal: import terminal logs, Oxidized/RANCID repositories and pasted text; segment sessions of the 7 target vendors; search them instantly (text, IP/prefix containment, MAC, ASN, community, interface); diff them over time; CLI + minimal local UI; publish `netcmd-safety` on PyPI.

Acceptance (from the roadmap): import 1 GB of logs in < 5 min on a regular laptop; search p95 < 100 ms; golden tests per vendor green on Windows/Linux/macOS.

Vendor IDs used everywhere: `cisco_ios` (IOS and IOS-XE), `cisco_xr`, `huawei_vrp`, `mikrotik_ros7`, `juniper_junos`, `nokia_sros`, `ipinfusion_ocnos`.

## Tasks

Each task is one branch and one PR. Tasks in the same step can run in parallel.

### Step 1: libraries (independent, parallel)

| # | Task | Done when |
|---|---|---|
| 1.1 | **netcmd-safety**: `classify(command, vendor, *, mode=None, version=None) -> Classification` with verdicts `READ`, `SESSION` (session-only settings such as paging), `CONFIG`, `DESTRUCTIVE`, `UNKNOWN`. Allowlist per vendor; unknown fails closed; pipes and output redirection handled; multi-line input returns the worst verdict. Test cases in YAML per vendor so contributors can add cases without Python. | Table tests per vendor; regression test that no write/config/destructive case is READ; hypothesis property tests; mypy strict; coverage ≥ 85% |
| 1.2 | **netprompt**: `detect_prompt(line)`, `detect_vendor(text)` (output fingerprints), `normalize(text)` (ANSI, backspaces, CR, pagination markers), `segment(text)` → `(prompt, command, output, line)` records. | Synthetic golden sessions for all 7 vendors, mixed-device sessions, property tests; coverage ≥ 85% |
| 1.3 | **netaddr-search**: IP/prefix parsing (CIDR, `ip mask`, wildcard), containment relations, SQLite-friendly fixed-width bounds for IPv4/IPv6, IP extraction from text; MAC normalization and extraction; interface-name normalization and aliases. | Hypothesis property tests for containment and normalization; coverage ≥ 85% |

## Working rules

- Feature branch per task, Conventional Commits, PR to `main`, CI green before merge, issues closed through PRs.
- No real device data in tests: synthetic sessions use documentation ranges (`192.0.2.0/24`, `198.51.100.0/24`, `203.0.113.0/24`, `2001:db8::/32`) and documentation ASNs (`64496–64511`, `65536–65551`).
- CHANGELOG and docs updated in the same PR as the feature.
